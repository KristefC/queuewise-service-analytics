
# QueueWise — Service Operations Intelligence

An end-to-end business analytics project using real NYC 311
service request data to investigate operational performance,
closure times, and service category patterns.

## Live Demo

[Launch QueueWise Interactive Dashboard] (https://queuewise-service-analytics-dznxkp4taup8ktjcg7pjjl.streamlit.app/)

Explore service request performance through:
- Interactive agency, borough, and category filters
- Dynamic operational KPIs
- Service category performance comparisons
- Downloadable analytical reports

## Tech Stack

- Python (pandas, NumPy)
- SQL (DuckDB)
- Power BI and DAX
- Streamlit and Plotly
- Git and GitHub
